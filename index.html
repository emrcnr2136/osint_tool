Reconnaissance & Footprinting

Passive analysis + live HTTP checks within browser permission boundaries.

Security Header Analyzer

Evaluates CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy, and X-Content-Type-Options over raw HTTP response header text.

—

Robots.txt & Sitemap Parser

Locally parses provided robots.txt or sitemap XML contents, listing user-agent rules and extracted URLs.

—

Directory / File Fuzzer

Sends limited GET/HEAD requests for selected paths if CORS permits. Results represent real HTTP responses.

Use only on authorized systems. Cross-origin targets on GitHub Pages may be blocked by CORS; results will reflect as "blocked".

Subdomain / VHost Discovery

Lists names appearing in public certificate logs via Certificate Transparency queries. Note that this does not verify active DNS resolution.

Vulnerability Assessment

Verifiable checks from within the browser; no exploit generation.

CORS Misconfiguration Checker

Evaluates ACAO / ACAC behavior based on provided response headers. Live URL probing operates if CORS is permitted.

Clickjacking / iframe Test

Loads the target inside a live iframe. Previews are blocked if X-Frame-Options or CSP frame-ancestors restrict framing.

SSL / TLS Certificate Lookup

Browser sandboxes do not directly expose TLS protocol/handshake specifics. This tool extracts issuer and validity details from Certificate Transparency logs, leaving the protocol field as "browser unavailable".

—

Form & Input Security Helper

Locally analyzes pasted HTML form markup: method, action, CSRF token naming conventions, password inputs, and autocomplete hints.

—

Crypto & Token Tools

Local parsing, hash calculation, and reversible encoding operations.

JWT Decoder & Validator

Decodes JWT Header and Payload via Base64URL, displaying standard claims and algorithms. Signature verification requires keys and is never falsely reported as successful.

—

Hash Identifier & Digest

Identifies likely hash families via hex length/patterns and calculates Web Crypto digests for SHA-1/SHA-256/SHA-384/SHA-512.

—

Base64 / URL / Hex Encoder

Encodes and decodes text across three standard web data formats using native UTF-8 TextEncoder/TextDecoder.

—

Payload Lab

Context/encoding test vectors and safe canary inputs instead of destructive exploit chains.

XSS Context Test Bank

Benign marker payloads designed to verify parser behavior across HTML, attribute, and JS-string contexts. Excludes WAF bypass collections.

—

SQLi Character Encoder

Encodes given characters into URL, hex, or numeric reference formats. Performs encoding transformations rather than generating SQLi exploit strings.

—

Path Traversal / LFI Test Matrix

Automatically generates variations to verify file retrieval controls without performing file content reading or exploitation.

—

Command Injection / SSRF Canary Templates

Harmless, traceable canary templates for verification. Does not provide ready-to-use exploits for remote code execution or metadata access.

—

Utilities & Helpers

Request/response simulation, regex extraction, and cross-origin network behavior utilities.

HTTP Request / Response Simulator

Composes and locally formats raw HTTP messages. The "send" action executes via browser fetch only if CORS permits.

—

Regex Pattern Extractor

Extracts emails, IPv4 addresses, URLs, endpoints, and custom regex pattern matches from text input.

—

CORS / Proxy Bridge Helper

GitHub Pages cannot independently "bypass" browser security boundaries. This tool computes required CORS response headers and does not act as a real third-party proxy server.

—

Settings

Browser-local settings. No data is transmitted to external servers.
